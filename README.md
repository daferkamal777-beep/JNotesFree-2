# JNotes Free V1

Free Flutter note-taking app for Android phones and tablets.

## Included in V1
- Arabic RTL interface
- Responsive phone/tablet home screen
- Create notes
- Multi-page note editor
- Pen / highlighter / eraser
- Adjustable stroke size and color
- Undo / redo
- Local persistence with SharedPreferences
- Dark/light theme
- Page thumbnails
- Basic text title
- Touch/stylus drawing

## Run
1. Install Flutter SDK.
2. Run `flutter pub get`.
3. Connect an Android phone/tablet or start an emulator.
4. Run `flutter run`.

## Build APK
`flutter build apk --release`

The generated APK will be under:
`build/app/outputs/flutter-apk/app-release.apk`
